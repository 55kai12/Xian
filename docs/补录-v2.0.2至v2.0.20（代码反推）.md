## 二、区间净变更（按主题）

### 1. 新增「倒数日」完整模块（本轮最大新增）

- 新增文件：`CountdownFragment.kt`、`CountdownViewModel.kt`、`CountdownAdapter.kt`、
  `data/Countdown.kt`、`data/CountdownDao.kt`、`res/layout/fragment_countdown.xml`、
  `res/layout/item_countdown.xml`
- 数据表 `countdowns`：`title / targetDate / repeatYearly / color / createdAt / sortOrder / linkedTaskId / note`
- 能力：按天显示「N 天后 / N 天前」（已过显示灰色）、支持「每年」重复并自动算下一个周年、
  颜色条、点击进详情、长按菜单
- 入口：任务页新增**左侧抽屉**（`fragment_tasks.xml` 外层由 `LinearLayout` 改为
  `DrawerLayout`，加 `menuButton` + 260dp 侧栏「更多功能 › 倒数日」）

### 2. 重复任务机制重构为「模板 + 每日快照」

这是本区间改动最深的一处，涉及数据模型、DAO、VM、UI 四层：

- `Task` 新增 `templateId: Int = 0`（0 = 模板或普通任务，非 0 = 某模板的完成快照）
- 数据库 `version 5 → 9`，新增 4 个迁移：
  - `5→6` 建 `countdowns` 表
  - `6→7` `countdowns` 加 `linkedTaskId`
  - `7→8` `countdowns` 加 `note`（⚠️ SQL 写成 `DEFAULT ''''`，实际默认值是一个单引号字符而非空串；
    因插入时总会赋值，暂无实际影响，可作为历史瑕疵记录）
  - `8→9` `tasks` 加 `templateId`；**清理旧版「完成即复制」堆出来的叠加副本**
    （每个 `title+repeatRule` 组只留 `MIN(id)` 一条）；保留的模板统一重置为未完成
- `TaskDao` 新增 `getCompletedSnapshot()` / `deleteCompletedSnapshot()`
- `TaskViewModel.toggleComplete()` 改三分支：
  1. 重复模板勾选 → 写入当天**完成快照**（`templateId=模板id`，模板本身保持未完成）
  2. 快照取消勾选 → 删除当天快照，模板当天恢复未完成
  3. 普通任务 → 照旧切换
- `TasksFragment` 新增 `buildOccurrencesForDay()` + `matchesRepeat()`：
  重复模板在适用的每一天生成虚拟实例；当天有快照则显示快照
- `TimerEngine`：**番茄钟不再把重复模板直接标完成**（否则模板每一天都会显示已完成），
  番茄记录仍照常计入统计
- `TaskViewModel` 新增 `doRefresh()` 并在多处调用，修「勾选后列表/序号不刷新」

### 3. 日记支持插入图片

- `ReviewFragment`：`ActivityResultContracts.OpenDocument` 选图 + 持久化 URI 权限、
  100dp 缩略图横向滚动容器、右上角删除按钮、点击全屏预览（黑色全屏 Dialog）、
  图片存 `review_prefs` 的 `images_<日期>`
- `fragment_review.xml` 新增「图片 ＋」标题栏与 `HorizontalScrollView/imagesContainer`
- 日记亮灯标（金/灰）判据由「有文字或有评分」扩展为**有文字或有评分或有图片**
- `strings.xml` 新增 `review_images` / `review_add_image` / `review_remove_image`

### 4. 新增独立「设置」页

- 新增 `SettingsFragment.kt` + `res/layout/fragment_settings.xml`
- 个人页 `fragment_profile.xml` 新增「设置」卡片（副标题：每日目标、关于、清除数据），
  `ProfileFragment` 加点击跳转（`addToBackStack`）

### 5. 新增「事件设置」页（任务列表显示项开关）

- 新增 `EventSettingsFragment.kt` + `res/layout/fragment_event_settings.xml`
- 配置项存 `event_settings` 这个 SharedPreferences：
  `show_order_number`（序号）、`show_strikethrough`（完成删除线）、
  `show_note`（备注）、`show_completed`（列表是否显示已完成）
- `TaskAdapter` 按开关决定序号/删除线/备注是否渲染；`TasksFragment.renderCurrentList()`
  按 `show_completed` 过滤

### 6. 法定节假日标记

- 新增 `HolidayStore.kt`（按固定规律判定节日区间，**不臆造调休**）+ `isShowHolidayEnabled()` 开关
- `CircleMonthView` / `CircleWeekView` 在日期底部绘制橙色小圆点（`0xFFE67E22`），
  月视图仅当前月生效

### 7. 统计口径打通（勾选完成也算）

- `FocusRepository`：今日 / 近 7 天 / 累计完成数，改为
  「番茄记录数 **+** 直接勾选完成的任务数」，与柱状图口径一致

### 8. 任务页 UI 调整

- 列表区改 `FrameLayout` 包裹、FAB 改 `bottom|end` 悬浮并提升阴影、列表底部留 80dp
  避免遮挡（`clipToPadding=false`）
- 周历收起高度 `56dp → 72dp` 并同步抽屉高度
- 新增任务对话框默认科目填「生活」；分类白名单补 `未分类` / 空值
- `pendingTasks` 收集由 `runCatching` 改为 `while(true)` + `try/catch` + 100ms 重试，
  避免流异常后列表永久停更

### 9. 锁机页布局

- `fragment_lock.xml`：开始/结束时间、保存/取消、悬浮窗权限/无障碍权限
  共 4+2 个按钮由竖排大按钮改为**两两并排**（`LinearLayout` + `layout_weight=1`）

### 10. 构建配置

- `app/build.gradle.kts`：`versionCode 201 → 220`、`versionName 2.0.1 → 2.0.20`
